# WordPress Plugin Requirements

[![Версия](https://img.shields.io/badge/version-0.1.0-blue)](CHANGELOG.md)

\[ [English](README.md) | **Русский** \]

**Узнайте, пройдёт ли плагин ревью, раньше ревьюера.**

Каталог плагинов WordPress.org - это фильтр, а не формальность. Ревьюер читает заголовок, readme, содержимое zip и те участки кода, которые работают с вводом, выводом, файлами, деньгами и внешними сервисами. Большинство отказов приходит из правил, которые опубликованы, но редко прочитаны целиком.

Этот скил - структурированный контрольный фильтр для ИИ-агента. **Класс скила:** оркестратор - файл маршрутизации плюс пять справочников по требованию. Он проверяет релизный артефакт по 18 Detailed Plugin Guidelines, готовит файлы, которые ревьюер читает первыми, и планирует SVN-релиз, который проходит автоматическую проверку безопасности.

Правила собраны из публичной документации WordPress.org, проверены 2026-11-16.

## Что делает

| Режим | Вход | Выход |
|---|---|---|
| `audit` | Плагин, релизный zip или репозиторий | Отчёт о находках с вердиктом |
| `prepare` | Цель или письмо ревьюера | Список правок, черновики readme и заголовка |
| `release` | Версия и план релиза | Схема SVN, тег, ассеты, чек-лист перед тегом |

Каждая находка содержит важность, ID правила, место, наблюдаемое доказательство и точную правку.

| Важность | Значение |
|---|---|
| `BLOCKER` | Риск отказа, закрытия или удаления |
| `FIX` | Ревьюер попросит исправить |
| `NOTE` | Полировка, риск утверждения или непроверенный пункт |

Вердикт: `READY`, `READY WITH FIXES` или `NOT READY`. Скил никогда не пишет «одобрено» и не даёт вероятность.

## Что ловит

- Заблокированный код, триал, квоты и лицензионные гейты в бесплатном плагине.
- Трекинг, телеметрия и сторонние запросы без явного согласия.
- Удалённый код, сторонние серверы обновлений, iframe в админке, CDN-ассеты.
- Встроенные библиотеки ядра, неподдерживаемый vendor-код, минифицированные ассеты без исходников.
- Отсутствие `ABSPATH`-защиты, неподготовленный SQL, неэкранированный вывод, отсутствие nonce.
- Несовпадения readme, заголовка, слага, версии и SVN.
- Заявления о юридическом соответствии и непроверяемые превосходные степени.

## Установка

```bash
git clone https://github.com/MADEVAL/Wordpress-Plugin-Requirements.git
cd Wordpress-Plugin-Requirements
python install.py --target all
```

Скил копируется в:

- **Claude Code:** `~/.claude/skills/wordpress-plugin-requirements`
- **OpenCode:** `~/.config/opencode/skills/wordpress-plugin-requirements`
- **Portable:** `~/.agents/skills/wordpress-plugin-requirements`
- **Codex:** `~/.codex/skills/wordpress-plugin-requirements`

Полезные флаги:

```bash
python install.py --list
python install.py --check
python install.py --target project --dry-run
```

Установщик копирует payload (`SKILL.md`, `agents/`, `references/`) и `LICENSE`. Тесты, evals и документация остаются в репозитории.

## Использование

```text
Проверь zip этого плагина по требованиям WordPress.org и скажи, что блокирует отправку.
```

```text
Разбери письмо ревьюера, исправь каждый пункт и подготовь ответ.
```

```text
Спланируй релиз 1.3.0: версия, readme, SVN-тег, ассеты.
```

Агент выбирает режим, собирает артефакт и нужные данные о версии и возвращает контракт вывода:

- Вердикт
- Область проверки
- Находки
- Readme и заголовки
- Безопасность
- Релиз
- Остаточный риск
- Следующие действия

Недостающие факты становятся `[VERIFY: ...]` или `not_checked`, а не догадкой.

## Структура репозитория

```text
skills/wordpress-plugin-requirements/
  SKILL.md              оркестратор, режимы, контракт вывода
  agents/openai.yaml    метаданные интерфейса OpenAI
  references/
    guidelines.md       жёсткие отказы и G1-G18
    submission.md       заголовки, readme.txt, SVN, ассеты
    security.md         ввод, вывод, SQL, файлы, i18n, приватность
    review.md           правила админки, блоки, авто-ревью, PCP
    audit.md            аудит из девяти шагов, переписывание заявлений, чек-лист
tests/
  validate_skill.py     структурный валидатор
  fixtures/bad-skill/   негативная фикстура
evals/cases.md          ожидаемое поведение по сценариям
```

## Проверка

```bash
python tests/validate_skill.py
python -m unittest discover -s tests -p "test_*.py"
```

Или в Windows:

```powershell
./run_tests.ps1
```

Валидатор проверяет frontmatter, обязательные секции, число правил, синхронизацию версии в readme, changelog и манифестах плагина, относительные ссылки и стиль текста (UTF-8 без BOM, LF, финальный перевод строки, только дефис). Специально сломанная фикстура обязана падать. CI запускает те же проверки на Python 3.12.

## Границы и дисклеймер

- Только плагины. Правила Theme Directory вне области.
- Это фильтр ревью, а не юридическая консультация и не официальное заявление.
- Решение принимает каталог. Ни один запуск скила не гарантирует одобрение.
- Правила меняются. Сверяйте список источников в `references/guidelines.md`.
- Нет аффилированности с WordPress.org, Plugin Directory, Automattic или WordPress Foundation. WordPress - товарный знак WordPress Foundation.
